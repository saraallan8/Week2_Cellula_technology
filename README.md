# Week 2 — LSTM Toxic Comment Classification

## Overview

This project is a Week 2 machine learning project that uses an **LSTM (Long Short-Term Memory)** neural network to classify text comments as **Toxic** or **Non-Toxic**.

The project includes the dataset, LSTM model, trained model, prediction results, and an application interface.
